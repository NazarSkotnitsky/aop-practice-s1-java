Програма vs Алгоритм: Алгоритм — це план дій (ідея), а програма — це код, яким цей план записано для комп'ютера.

Навіщо мови програмування: Вони створені для людей, щоб писати код зручно, а компілятор потім переводить їх у машинний код (нулики й одинички) для процесора.

Чи може комп'ютер зробити щось не за інструкцією: Ні, він виконує лише закладені правила та код.

Рецепт борщу: Так, це алгоритм (послідовність кроків до результату), але з менш суворими правилами (наприклад, «сіль за смаком»).

Як зав'язати шнурки: Схрестити кінці ➔ зав'язати базовий вузол ➔ сформувати петлю ➔ обернути другим шнурком ➔ протягнути в отвір і затягнути обидві петлі.

Чи доводить успіх на тестах з дошки безпомилковість програми: Ні. Це підтверджує правильність лише для конкретних прикладів, але не виключає помилок на інших вхідних даних.
