Навіщо потрібні окремі типи для цілих і дробових чисел? Цілі типи (int, long) зберігають значення абсолютно точно і працюють швидше на рівні процесора.Дробові типи (float, double) призначені для збереження неперервних величин і вимірювань із дуже великим або дуже малим діапазоном значень.Що означає «рухома кома» і куди вона рухається? Положення роздільника (коми) не зафіксоване жорстко, а залежить від порядку числа: 
M×2E. Кома «рухається» ліворуч або праворуч під час нормалізації числа для збереження максимальної точності.Скільки цифр після коми комп'ютер здатен запам'ятати? За стандартом IEEE 754:float (32 біт) забезпечує точність близько 6–9 десяткових цифр.double (64 біт) забезпечує точність близько 15–17 десяткових цифр.Чому 0.1+0.2≠0.3? У двійковій системі числення числа 0.1 та 0.2
 перетворюються на нескінченні періодичні двійкові дроби. Через обмеження пам'яті відбувається округлення, тому сума виходить рівною приблизно 0.30000000000000004.Чому гроші ніколи не зберігають у double? Помилки округлення типів із плаваючою комою накопичуються під час розрахунків, що неприпустимо у фінансах. Для грошей використовують цілі числа (збереження у копійках/центах) або клас точності BigDecimal.Чи може число не дорівнювати саме собі? Так. Спеціальне значення NaN (Not a Number — "не число", яке виникає, наприклад, при діленні 0.0 / 0.0) за стандартом IEEE 754 володіє властивістю NaN != NaN. Вираз Double.NaN == Double.NaN повертає false.
