1. Чому комп'ютер рахує двійками, а не десятками, як ми?Відповідь: Апаратна частина (транзистори) найстабільніше працює у двох дискретних станах: є сигнал (1) або немає сигналу (0). Це мінімізує ризики збоїв і перешкод в обробці даних.2. Що таке біт і чому саме вісім бітів назвали байтом?Відповідь: Біт — мінімальна одиниця інформації (0 або 1). Байт історично закріпився як блок із 8 бітів у ранніх комп'ютерних архітектурах (зокрема IBM), оскільки цього обсягу було достатньо для кодування одного символу алфавіту, що зручно кратно ступеням двійки ($2^3 = 8$).3. Як записати від'ємне число, якщо в пам'яті є лише нулі й одиниці?Відповідь: Використовується доповняльний код (two's complement). Старший біт виділяється під знак (0 — плюс, 1 — мінус). Для отримання від'ємного числа інвертують усі біти додатного значення (міняють 0 на 1 і навпаки) і додають до результату одиницю.4. Чому виникає переповнення і як з ним боротися?Відповідь: Переповнення трапляється, коли результат арифметичної операції перевищує максимальне значення для виділеної кількості бітів (пам'яті). Методи боротьби: використання більших типів даних (long замість int), перевірка меж перед виконанням операцій або застосування класів довільної точності (BigInteger).5. Чому в старих іграх максимум золота — рівно 2 147 483 647?Відповідь: Це максимальне додатне число для 32-бітного цілочисельного типу зі знаком (int32), діапазон якого складає від $-2^{31}$ до $2^{31}-1$. У старій ігробудівній індустрії саме цей тип найчастіше виділявся під лічильники ресурсів.6. Чому комп'ютер вважає, що 7 / 2 = 3?Відповідь: Це наслідок цілочисельного ділення (integer division). Якщо обидва операнди є цілими числами (int), дрібна частина відкидається без округлення. Щоб отримати дійсне значення (3.5), хоча б одне з чисел слід записати як дробове (7.0 / 2 або 7 / 2.0).
